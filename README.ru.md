## ✨ Новое в 1.3.0 — ваш аккаунт Sakina

- **Аккаунт Sakina:** регистрация по e-mail с подтверждением, вход, восстановление пароля — ссылка из письма открывает программу. Сеанс хранится зашифрованным (Windows DPAPI) и восстанавливается при запуске.
- **Знакомство при первом запуске:** как к вам обращаться (любой алфавит, включая таджикские буквы), откуда узнали о Sakina, для чего и на каком языке общаться (Русский / Тоҷикӣ / English) — с продолжением с того же шага.
- **Персональное общение:** «Добрый вечер, Алекс!» по часам компьютера; локальные модели знают ваше имя и используют его естественно. Имя передаётся как данные, а не инструкция; облачным моделям — только если вы включите.
- **Карточка аккаунта** в боковой панели и **Настройки → Аккаунт и профиль:** имя, язык, e-mail, пароль, персонализация, выход.
- **Офлайн-режим:** настроенный аккаунт открывается без интернета — локальные модели, чаты и настройки работают.
- **Настройки рабочего места** рядом с «Задачами»: шрифт редактора и терминала, автосохранение, форматирование и очистка при сохранении, отступы, перенос строк, миникарта, оболочка, ИИ-автодополнение.
- **«Обучение» проверяет компьютер** (процессор, память, все видеокарты, диск) и оценивает 35 популярных моделей Ollama: где каждая будет работать, сколько памяти нужно, скорость и поддержка LoRA.

## ✨ Новое в 1.2.1 — функции Claude Code и настоящая IDE

- **Контрольные точки и откат** (как `/rewind` в Claude Code). У каждого сообщения есть «Откатить сюда», в поле ввода работает `/rewind`: можно вернуть **код и диалог**, только диалог или только код. Файлы, которые агент изменил, создал или удалил после сообщения, восстанавливаются, а само сообщение возвращается в поле ввода.
- **Субагенты (инструмент `task`).** Агент поручает широкий поиск субагенту с отдельным контекстом и правами только на чтение — при желании в роли одного из ваших агентов — и получает краткий отчёт.
- **Агент задаёт вопросы** (как AskUserQuestion): варианты-карточки, клавиши 1–5, свой ответ или «Пропустить».
- **Фоновые процессы.** Dev-серверы, watcher-ы и долгие сборки работают в фоне; агент читает только новый вывод и останавливает их. Новая панель **«Процессы»** показывает живой вывод, кнопки «Остановить» и «Отправить в чат».
- **Хуки** («Настройки → Хуки»), совместимые с Claude Code: ваши команды на `PreToolUse`, `PostToolUse`, `UserPromptSubmit` и `Stop`; JSON в stdin, код выхода 2 блокирует. Шесть шаблонов (Prettier после правок, запрет `git push --force`, защита `.env`, журнал команд…) и кнопка «Проверить». Хуки добавляете только вы — из файлов проекта они не берутся.
- **Рабочее место — полноценная IDE:** **Ctrl+P** с нечётким поиском и переходом `file.ts:42`, панель **«Задачи»** (скрипты package.json для npm/pnpm/yarn/bun, Makefile, Cargo, Go, .NET, Python/Django, Flutter, deno — запуск в один клик), **строка состояния** (ветка Git, ошибки и предупреждения, процессы, строка/столбец, отступы, кодировка, конец строки, язык), **хлебные крошки** и **меню вкладок**.
- **Дизайн:** единый стиль заголовков страниц, фирменная полоса прокрутки в сайдбаре, статус на странице «Обучение» больше не обрезается.

## ✨ Новое в 1.2.0

- **«Обучение» — учите свои локальные модели.**
  - Готовые курсы: «Таджикский язык», «Работа с данными», «Анализ данных», «Создание агентов», «Популярные фреймворки», «Тестирование проектов», «Деловые документы» — или свой курс.
  - Сборка новой модели Ollama со встроенными ролью, параметрами и примерами.
  - Примеры: вручную, импортом JSONL/CSV или генерацией с ИИ, в том числе по вашим документам.
  - **Тестирование обученной модели в сравнении с базовой.**
  - Полный **набор LoRA-дообучения** подстраивается под любую видеокарту NVIDIA — от GTX 1050 до RTX 5090 и A6000. Размер модели, bf16/fp16, размер пакета, экономия памяти и нужная CUDA-сборка PyTorch выбираются автоматически. Без видеокарты обучение идёт на процессоре.
- **«Агенты» — создайте своего.**
  - Инструкции, режим, модель, возможности и **знания из ваших документов**.
  - Черновик агента от ИИ по одному предложению и 10 шаблонов.
  - **192 агента из самых популярных GitHub-коллекций** в один клик.
  - **27 известных открытых агентных проектов** (AutoGPT, Dify, OpenHands, CrewAI, LangGraph…) для скачивания и изучения.
  - Агента можно выбрать для любого чата рядом с «Режимом».
- **Доступ «Авто» (рекомендуется):** агент работает внутри проекта без остановок на вопросы. Спрашивает только об опасных действиях и о действиях вне проекта.

## ✨ Новое в 1.1.8

- **Исправлено: генерация в Design обрывалась на 94–95 % с «Генерация отменена».** Большие презентации больше не обрезаются общим лимитом времени; запрос прерывается, только если модель долго молчит, истечение времени — понятная ошибка с кнопкой «Повторить» (а не «отмена»), временная перегрузка повторяется сама («попытка 2 из 3»), а полностью полученный дизайн сохраняется, даже если связь оборвалась в конце.
- Тайм-аут провайдера теперь везде — **тайм-аут простоя**: длинные ответы в чате и у агента идут до конца, пока модель пишет.
- **503 «high demand»** у Gemini показывается понятным сообщением «модель временно перегружена» и повторяется автоматически.

## ✨ Новое в 1.1.7

<img src="docs/screenshots/29-voice-input.png" alt="Голосовой ввод в поле сообщения" width="900" />

- **Голосовой ввод**, как в ChatGPT и Claude: кнопка микрофона рядом с «Отправить». Пока вы говорите, в поле видны живая волна и таймер; «Стоп» (или Enter) превращает речь в текст на месте курсора — отправьте сразу или сначала поправьте. «✕» или Esc отменяет; **Ctrl+Shift+M** начинает и заканчивает диктовку.
- Распознавание — через ваших провайдеров: API, совместимые с Whisper (OpenAI, Groq, локальные серверы Whisper), или Gemini. Провайдер, модель и язык речи (авто, русский, английский, таджикский) — в *Настройки → Общие → Голосовой ввод*. Запись уходит только этому провайдеру и не сохраняется; в режиме «Только локально» — только на ваши локальные серверы.
- **Понятные ошибки квоты**: длинный ответ Google о квоте показывается одной строкой; модель без квоты на вашем тарифе (*limit: 0*) так и называется, а проверка подключения сама находит работающую модель.

## ✨ Новое в 1.1.4

<img src="docs/screenshots/15-ai-workspace.png" alt="Пространство ИИ — виджеты, созданные из чата" width="900" />

- **Пространство ИИ (Generative UI).** Меняйте программу обычными словами — *«Добавь календарь справа в стиле Liquid Glass»*, *«Сделай его шире»*, *«Покажи загрузку процессора и видеокарты»*, *«Верни как было»*. Модель составляет декларативные проверяемые операции; 12 рабочих виджетов (календарь, задачи, заметки, калькулятор, часы, монитор системы и GPU, монитор модели, графики, KPI-карточки, таблицы, прогресс, свои), перетаскивание между правой панелью, дашбордом и плавающими панелями, отмена/повтор со снимками, экспорт и импорт. Работает с любой подключённой моделью — локальной или облачной.
- **Безопасные виджеты от ИИ.** Сгенерированный код выполняется только в изолированной песочнице (свой источник, строгий CSP, без сети, Node.js и IPC) после того, как вы проверите разрешения и подтвердите установку; любую версию можно откатить.
- **Design** — как Claude Design: **Слайды**, **Дизайн**, **Дизайн в кодовой базе** (учитывает токены и стек вашего проекта) и **Дизайн-система**. Доработка текстом, история версий, предпросмотр на компьютере / планшете / телефоне, показ на весь экран, экспорт в **PowerPoint**, **PDF** и **HTML**.
- **Настоящее рабочее место.** Правый клик по файлу или папке: новый файл/папка, переименование, вырезать/копировать/вставить, дублировать, удалить (с восстановлением), копировать путь, показать в проводнике, открыть в программе по умолчанию. Встроенный просмотр **Word, Excel, PowerPoint**, изображений, PDF, аудио и видео.
- **232 навыка** — +132 профессиональных навыка для программирования и дизайна (ui-ux-pro-max, Vercel, Emil Kowalski, Matt Pocock, wshobson/agents, GSAP, Supabase, Android, WordPress…), категории, сортировка, готовые наборы в один клик и обновление с GitHub.
- **Число скачиваний каждой версии** в *Настройки → Обновления*, **проверка обновлений** в *О программе* и уведомления в стиле iOS.

## Почему Sakina

- **Любая модель в одном приложении.** OpenAI, Anthropic Claude, Google Gemini, OpenRouter, Groq, DeepSeek, Mistral, Moonshot Kimi и любой OpenAI-совместимый API — **и ваши собственные модели**: Ollama, Open WebUI, vLLM, SGLang, llama.cpp, LM Studio, Kimi K2 (своя установка) и ещё 20 типов локальных и сетевых серверов.
- **Приватность.** Никакой телеметрии. Чаты, проекты и настройки хранятся на вашем компьютере, ключи API зашифрованы Windows DPAPI. Конфиденциальные проекты можно направлять только на локальные модели.
- **Агент, который действительно работает.** Читает и правит файлы, запускает команды в терминале, работает с Git — каждое рискованное действие ждёт вашего подтверждения, а каждый шаг виден на ленте.
- **Расширяемость как в Claude.** Skills (SKILL.md), Коннекторы (MCP) и Плагины (формат Claude Code) — самые популярные устанавливаются с GitHub в один клик.
- **Обновляется сама.** Новая версия находится на GitHub Releases, скачивается с прогрессом, проверяется (SHA-512) и устанавливается одной кнопкой — данные сохраняются.

## Установка

1. Скачайте **`Sakina-AI-Desktop-Setup-<версия>.exe`** из [последнего релиза](https://github.com/imomzoda-dev/SakinaAiDesktop/releases/latest).
2. Запустите и следуйте мастеру (установка для себя или для всех пользователей, выбор папки).
3. Windows SmartScreen может предупредить, потому что установщик пока не подписан сертификатом: нажмите **Подробнее → Выполнить в любом случае**.

**Требования:** Windows 10 или 11 (x64), 4 ГБ ОЗУ (рекомендуется от 8 ГБ), около 500 МБ на диске. Node.js нужен только для локальных MCP-коннекторов (npx).

### Обновление

Sakina проверяет GitHub Releases при запуске и каждые 4 часа (отключается в *Настройки → Обновления*). Когда выходит новая версия, в сайдбаре плавно появляется карточка: **GitHub** открывает описание релиза, **Обновить** скачивает его с прогрессом, проверяет SHA-512 и предлагает **Перезапустить и обновить**. Можно обновиться и вручную — новый установщик покажет «Обновление 1.x → 1.y» вместо «Установить» и сохранит чаты, проекты, настройки и ключи.

## Своя модель на другом компьютере

```bash
# На компьютере с видеокартой (пример для Ollama): слушать локальную сеть
setx OLLAMA_HOST 0.0.0.0
ollama serve
```

В Sakina: **Модели → Локальный ИИ → Добавить локальный сервер**, выберите тип (Ollama, Open WebUI, vLLM, SGLang, LM Studio, Kimi K2…), укажите IP и нажмите **Проверить**. Если по адресу работает другой сервер (например, страница Open WebUI вместо её API), проверка это распознает и предложит **Применить**.

## Приватность

- Без телеметрии, аккаунтов и рекламы.
- Данные хранятся в `%APPDATA%\sakina-ai-desktop` на вашем компьютере.
- Запросы уходят только выбранным вами провайдерам и коннекторам; проверка обновлений обращается к GitHub.
- Ключи API и токены коннекторов зашифрованы Windows DPAPI и не попадают в журналы и экспорт.
