# Журнал изменений

## 1.1.2

- **Skills** — новый раздел, как в Claude: навыки в формате SKILL.md (Agent Skills). Каталог из 100 популярных навыков с GitHub (Anthropic, obra/superpowers, addyosmani/agent-skills и др.) с установкой в один клик, создание своих навыков, импорт из папки, .zip или по ссылке GitHub. Модель сама подключает подходящий навык (инструмент `use_skill`) — даже в обычном чате; навык можно вызвать явно командой `/имя`.
- **Коннекторы** — каталог из 19 проверенных MCP-коннекторов (GitHub, Context7, DeepWiki, Microsoft Learn, Playwright, Chrome DevTools, Notion, Brave Search, Exa, Tavily, Firecrawl, Figma, Supabase, Sentry и др.) с подключением в один клик; токены хранятся в зашифрованном виде.
- **Плагины** — каталог официального маркетплейса Anthropic (315 плагинов) и любых маркетплейсов GitHub в формате Claude Code: навыки, slash-команды и коннекторы из плагинов работают в Sakina.
- **Автообновление** — при запуске и каждые 4 часа Sakina проверяет GitHub Releases; в сайдбаре плавно появляется карточка «Доступна версия…» с кнопками «GitHub» и «Обновить», затем прогресс загрузки, проверка SHA-512 и «Перезапустить и обновить».
- **Open WebUI** — новый тип локального сервера и автоопределение: если по адресу работает другой сервер (Open WebUI, Ollama, OpenAI-совместимый), проверка подключения предлагает исправление в один клик.
- Слишком большое «Макс. токенов ответа» больше не ломает запросы (ограничивается размером контекста).
- Лицензия: бесплатная проприетарная EULA.


## 1.1.1

- Значок на панели задач, в окне и в трее — логотип Sakina (S): файлы иконок теперь поставляются вместе с программой (раньше они не попадали в сборку, и Windows показывала значок Electron, а значок в трее был пустым).
- Gemini и другие провайдеры, у которых не выбрана модель по умолчанию, больше не дают ошибку «Модель не выбрана»: после проверки подключения сохраняется подходящая модель (для Gemini — стабильная быстрая, например gemini-2.5-flash), а уже сохранённые подключения исправляются при запуске.
- Проверка подключения: короткий потоковый ответ одним фрагментом больше не помечается предупреждением.

## 1.1.0

- Боковая панель: кнопка у логотипа плавно сворачивает её в узкую полосу с иконками (с подсказками) и разворачивает обратно; ширину можно менять перетаскиванием края (двойной щелчок — по умолчанию), Ctrl+B тоже работает.
- Локальные серверы: добавлены Kimi K2 (своя установка через vLLM / SGLang / KTransformers), SGLang, KTransformers, LMDeploy, TensorRT-LLM, NVIDIA NIM, Xinference, Jan, GPT4All, KoboldCpp, text-generation-webui, TabbyAPI, Aphrodite, MLC LLM, llamafile, Docker Model Runner, Lemonade (AMD), exo, OpenLLM, LiteLLM — всего 27 типов; у каждого в списке виден порт и путь API.
- Облачный провайдер Moonshot AI (Kimi).
- Подсветка кнопок окна (свернуть / развернуть / закрыть) больше не выходит за заголовок.
- Переключатели: во включённом состоянии бегунок снова с ровным отступом.
- Значок на панели задач Windows — логотип Sakina (S) вместо значка Electron.
